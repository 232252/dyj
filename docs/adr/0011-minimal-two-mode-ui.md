# ADR-0011：v0.4 极简信息架构——4 路由、无侧栏、角色即主页、零设置

- **状态**：已接受
- **日期**：2026-09-30
- **依据**：[调研 14](../research/14-minimal-two-mode-redesign.md)（v0.4 详细设计：
  现状体检、4 页面线框、自动化行为规格、检查点增量、改动映射）
- **前置**：[ADR-0010](0010-role-wizard-pairing.md)（v0.3 角色向导与配对，已实现）

## 背景

v0.3 按调研 13 全量实现并真机验收后，用户反馈：**功能对了，但界面仍是
"后台控制台"**——7 项侧栏、8 条路由，网络页暴露端口/TLS/mDNS/主机名/网卡，
状态页摆着 URI、后端名、指标卡与三平台手工添加命令。用户重申理想流程：
安装 → 托盘角标 → 浏览器里只有「服务端」「客户端」两个方向；服务端自动
扫描、一键共享、显示 4 位码、后台自行运行；客户端自动扫描、点击添加、
输 4 位码、装完 WPS 直接可见；队列可以有但极简；**不要"高级"设置，
一切自动适配**；同时检查点、日志、调试必须做扎实（自动化越多越易错）。

## 决策

### D1. 全产品 4 条路由、无侧栏、角色即主页

`#/`（未配置 = 服务端/客户端两卡片）、`#/server`、`#/client`、`#/help`。
`config.role` 决定默认主页（share→server、use→client、both→server+页脚入口、
`""`→两卡片）；页面间跳转仅两卡片互跳与右上角 [?]。旧 hash 重定向保书签。

### D2. 用户可见界面零设置项、零工程术语

网络页与打印机管理页**整页删除**；URI/指标卡/手工添加指引从状态页移除。
端口、防火墙、mDNS、驱动、队列名、连接地址等 11 项全部转为自动化行为规格
（调研 14 §4，每项 = 策略 + 兜底 + 检查点 + 人话四件套）。
CLI 与 `service.json` 是唯一的"高级"出口，UI 不提供。

### D3. 向导完成后原地变主页，不再进入控制台

服务端页 = 挑选态（自动枚举、默认全选、一键共享）/ 主页态（配对码大字 +
共享清单逐台开关 + 已连设备 + 最近打印 8 行）双状态；客户端页 = 添加流 /
已安装列表（含就绪/离线/被撤销状态列）双状态。无 stepper 视觉。

### D4. 文案规范是硬约束

禁用词表（URI、端口、后端、队列名、mDNS、IPP、token、host…）+ 人话映射表
（技术事件 → 唯一允许的用户话术），验收含禁用词 CI 扫描（调研 14 §3.6）。

### D5. 帮助页是唯一技术信息区，带诊断导出

自检（doctor 按角色）、日志（只读折叠）、关于（版本/端口）全收进 `#/help`；
新增 `GET /admin/api/diag/export` 诊断包（日志尾 + 自检结果 + 脱敏 config），
面向"用户只会发文件"的远程求助场景。

### D6. 技术底座零推翻

配对协议、装系统队列、热生效、多打印机、logx、托盘全部沿用 v0.3 实现；
后端仅三小增量（jobs `limit`、added-printers `status` 字段、diag 导出）。
检查点契约继承 ADR-0010 D7 的 24 项，新增 UI-1..4 与 DIAG-1..2
（调研 14 §6.1）。

## 备选方案与拒绝理由

- **保留侧栏、只精简各页**：不解决"每次进来先做导航决策"的病根；用户
  明确要求"进去引导只有两个方向"。
- **原生 GUI 重写（Wails/WebView2 壳）**：Web 栈与全部组件已存在且经真机
  验收；重写不减少信息，只换壳。
- **把"高级设置"收成折叠面板留在主页**：折叠面板仍是设置项，用户原话
  "高级也不用"——一律不进 UI。

## 后果

- 删除 `page-printer.js`、`page-network.js` 与 7 项侧栏；`app.js` 路由重写；
  dashboard 拆分；i18n 按文案规范重写（改动集中在前端，后端近乎零新增）。
- `service.json`/配对/已装队列数据结构不变，v0.3 升级零迁移。
- 验收标准 = 调研 14 §8（4 路由断言、2/4 次点击预算、故障演练 5 分钟定位、
  v0.3 升级无损）。
- 调研 14 §9 的五个问题已在 v0.4.2 关闭或标成现场项：both 角色按
  服务端主页落地；最近打印随 spool 持久化；手机端仍不承诺（不声明 URF）；
  安装完成页默认勾选打开 dyj；旧 hash 重定向至少留到 v0.6。
