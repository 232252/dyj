# ADR-0014：放弃鸿蒙 App 与配对即信任，改用限时「开放打印模式」

- **状态**：已接受
- **日期**：2026-11-09
- **取代**：[ADR-0012](0012-harmony-receiver-rnoh.md)、[ADR-0013](0013-harmony-system-print-integration.md)

## 背景

ADR-0012→0013 一路演进到「系统打印接管 + 配对即信任设备 IP」（commit 196f55f/6660e7c）。实际使用后用户判断：手机/平板打印只需要**免认证**这一件事——鸿蒙 App、配对即信任、631 别名、mDNS 周期重宣告这些配套都是过度工程。服务端回归鸿蒙开发之前的行为（af58bf0），换一个所有端通用的机制。

## 决策

1. **回退**：删除 `harmony/` App；回退「配对即信任 IP」（`pairing.TrustedIP`）；回退 631 端口别名与 mDNS TTL/2 周期重宣告。数据面门禁回到 ADR-0010 的「loopback 或令牌」。
2. **新增「开放打印模式」**（通用，不针对任何平台）：
   - 默认关闭；
   - 开启默认 **10 分钟自动关闭**（内存态，重启即失效，惰性过期，无定时器）；
   - 可选**一直开启**：持久化进 `service.json`（`open_print`），管理页须确认风险提示后才能开启；
   - 开启期间 IPP 数据面免令牌（gate 顺序：loopback → 令牌 → 开放模式 → 401），每次免令牌放行记 `allow.ipp` 审计事件（含来源 IP），与 `deny.ipp` 对称；
   - `/admin`、`/pair` 与管理 API 仍需令牌，**不**随开放模式放开。
3. **黄金字节保留**：`pkg/client` 的 golden test 与 fixture 与鸿蒙无关，作为 Go 侧 wire 锁定继续保留。

## 后果

- 正面：机制从「按设备记 IP」简化为「按时间开窗」，任何平台任何客户端（含系统打印栈）都适用，无需 App；默认关 + 限时窗让风险暴露最小化。
- 风险：一直开启 = 局域网任何人可打印。威胁模型维持「防随意蹭打，非防坚决攻击者」（与 4 位 PIN 同级），UI 明示风险；10 分钟窗重启即失效，常开跨重启但管理页一键可关。
- 调研 16/17 与 ADR-0012/0013 保留为决策史；research/17 §4 真机实验不再回填。
